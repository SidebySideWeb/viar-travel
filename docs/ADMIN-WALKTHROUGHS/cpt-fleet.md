# Walkthrough — Fleet (custom post type)

## Create a new fleet vehicle / option

1. Go to `Fleets → Add New`.
2. Set:
   - **Title** (vehicle name)
   - **Excerpt** (short description used on cards)
3. Fill the ACF fields:
   - **Fleet Card Label** (small label above title on listing cards)
   - **Fleet Card Image** (used on VIP Transfers grid)
   - **Fleet Hero Image (Single Page)** (used on the fleet detail page)
   - **BookingPress Shortcode** (booking form to show on the single fleet page)
4. Click **Publish**.

## Edit an existing fleet item

1. Go to `Fleets`.
2. Click the item title.
3. Update fields and click **Update**.

### Verify

- Fleet appears in VIP Transfers grid.
- Fleet single page shows hero image + booking form (if shortcode present).
