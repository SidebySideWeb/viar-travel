# Walkthrough — VIP Transfers page

This page contains a designed layout and a **Fleet grid** that pulls from Fleet posts.

## Edit the hero image (ACF)

1. Go to `Pages → VIP Transfers` (or “VIP Transfers Services”, depending on the page title).
2. Scroll to **ViaR Hero Content**.
3. Update **Hero Image**.
4. Click **Update**.

## Update the fleet cards shown on the page

Fleet cards come from published **Fleet** posts.

1. Go to `Fleets`.
2. Add or edit a Fleet item.
3. Ensure these are filled:
   - **Title**
   - **Excerpt**
   - ACF: **Fleet Card Label**
   - ACF: **Fleet Card Image**
4. Publish/Update.

### Verify

- Refresh the VIP Transfers page and confirm the fleet grid is updated.
