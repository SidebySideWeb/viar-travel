# Walkthrough — Footer content + Logo subtitle (Google schema tagline)

## Edit the subtitle under the footer logo (also used in schema)

This controls:

- The **text under the footer logo**
- The Organization **`slogan`** and **`description`** values in Rank Math JSON-LD

Steps:

1. Go to `Appearance → Customize → ViaR Footer Content`.
2. Edit **Logo Subtitle (footer & schema)**.
3. Click **Publish**.

### Verify

- Scroll to the footer and confirm the subtitle text appears under the logo.
- Optional: test schema on a page using Google Rich Results Test.

## Edit footer phone + email

1. Go to `Appearance → Customize → ViaR Footer Content`.
2. Edit:
   - **Concierge Phone**
   - **Concierge Email**
3. Click **Publish**.

### Verify

- Footer contact line updates.
- Email link opens correctly.

## Edit footer copyright

1. Go to `Appearance → Customize → ViaR Footer Content`.
2. Edit **Copyright Text**.
3. Click **Publish**.

## Edit footer tagline (italic line at the very bottom)

1. Go to `Appearance → Customize → ViaR Footer Content`.
2. Edit **Footer Tagline**.
3. Click **Publish**.
