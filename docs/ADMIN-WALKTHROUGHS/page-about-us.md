# Walkthrough — About Us page

## Edit the “designed” About layout (ACF fields)

1. Go to `Pages → About Us`.
2. Scroll to **ViaR Hero Content** fields.
3. Update:
   - Hero Eyebrow
   - Hero Title
   - Hero Description
   - Hero Image
   - Card / Secondary Image (used by the template)
   - Hero CTA Label + URL (if used)
4. Click **Update**.

### Verify

- Open `/about` on the live site and confirm the hero and images updated.

## Editor override (optional)

If you add block content in the WordPress editor, it will override the designed template.
