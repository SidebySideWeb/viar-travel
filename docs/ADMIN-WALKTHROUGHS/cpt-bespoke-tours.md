# Walkthrough — Bespoke Tours (custom post type)

## Create a new tour

1. Go to `Bespoke Tours → Add New`.
2. Set:
   - **Title**
   - **Excerpt** (used on listing cards)
3. In the ACF fields (“ViaR Bespoke Tour Fields”), fill the sections:
   - Listing → **Tour Card Image**
   - Hero & Introduction → hero image, intro lead/body, etc.
   - At a Glance → duration/location/pace/best season
   - Curated Experiences → experiences 1–3
   - Quote → pull quote + attribution
   - Inquiry CTA → CTA title/description/button/link + optional brochure
   - Booking → optional BookingPress shortcode
4. Assign taxonomy terms:
   - Regions
   - Experience Types
5. Click **Publish**.

## Edit an existing tour

1. Go to `Bespoke Tours`.
2. Click the tour title.
3. Make changes and click **Update**.

### Verify

- Tour appears on `/bespoke-tours` listing.
- Single tour page looks correct.
