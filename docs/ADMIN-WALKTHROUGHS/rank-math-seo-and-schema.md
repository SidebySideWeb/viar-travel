# Walkthrough — Rank Math SEO & Organization schema

## Edit SEO on a page/post

1. Edit the Page/Post in WordPress.
2. Find the Rank Math panel (usually in the editor sidebar or below the editor).
3. Update:
   - SEO title
   - Meta description
   - Social preview (optional)
4. Update/Publish.

## Organization schema (logo + tagline)

The theme adds/merges Organization JSON-LD through Rank Math.

These values are controlled here:

- **Logo**: `Appearance → Customize → Site Identity → Logo`
- **Slogan/Description**: `Appearance → Customize → ViaR Footer Content → Logo Subtitle (footer & schema)`
- **Telephone/Email**: `Appearance → Customize → ViaR Footer Content`

## Verify schema output (optional)

- Use Google Rich Results Test on any page URL.
- Confirm Organization shows your logo and the slogan/description text.
