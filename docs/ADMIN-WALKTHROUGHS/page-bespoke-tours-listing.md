# Walkthrough — Bespoke Tours (listing page)

This is the page that lists tour cards and provides filters (Region / Experience Type).

## Edit the listing page hero

1. Go to `Pages → Bespoke Tours`.
2. Scroll to **ViaR Hero Content**.
3. Update:
   - Hero Title
   - Hero Description
   - Hero CTA Label
   - Hero CTA URL
4. Click **Update**.

## Manage the filters (Region / Experience Type)

Filters are taxonomy terms assigned to Bespoke Tour posts.

1. Go to `Bespoke Tours`.
2. Edit a tour and assign:
   - **Regions**
   - **Experience Types**
3. Update/Publish.

## Control which tours appear

Only **Published** Bespoke Tours appear on the listing.

## Booking form on this page (BookingPress)

This page includes a BookingPress form via shortcode in the template. If you need to change the service ID, that requires a developer change (or the shortcode can be made editable via admin).
