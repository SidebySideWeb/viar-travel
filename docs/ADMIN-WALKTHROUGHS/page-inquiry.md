# Walkthrough — Inquiry page

## Edit the hero content (ACF)

1. Go to `Pages → Inquiry`.
2. Scroll to **ViaR Hero Content**.
3. Update:
   - Hero Eyebrow
   - Hero Title
   - Hero Description
   - Hero Image
   - Card / Secondary Image
   - Hero CTA Label (used as a heading later on the page)
4. Click **Update**.

## Edit the inquiry form

The Inquiry page currently uses a built-in (hardcoded) HTML form inside the template, not WPForms.

If you want the Inquiry form submissions to email you / save entries / integrate with CRM, the best approach is to replace it with a WPForms form and embed a shortcode.
