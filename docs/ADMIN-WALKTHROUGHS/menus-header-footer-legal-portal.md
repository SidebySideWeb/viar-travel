# Walkthrough — Menus (Header, Footer, Legal, Client Portal)

## Which menu location is which?

- **Primary Menu**: header navigation
- **Footer Menu**: footer “Explore” list
- **Legal Menu**: footer “Legal” list
- **Client Portal Menu**: private client navigation pages

## Edit menu items (rename / reorder / add / remove)

1. Go to `Appearance → Menus`.
2. In **Select a menu to edit**, choose the menu (e.g. “Primary Menu”) and click **Select**.
3. Make changes:
   - Drag items to reorder.
   - Expand an item to rename it.
   - Use the left panel to add Pages, Custom Links, etc.
4. Click **Save Menu**.

### Verify

- Header menus: refresh the site and check the header navigation.
- Footer menus: scroll to footer and check “Explore” and “Legal”.
