# Walkthrough — Contact page

## Edit the contact form (WPForms)

1. Go to `WPForms → All Forms`.
2. Open the form with ID **15**.
3. Edit fields, notifications, and confirmation message.
4. Save.

### Verify

- Submit a test entry on the Contact page and confirm emails are received.

## Edit the Contact page text

Some Contact page text is currently hardcoded in the page template, not in admin fields.

If you need the hero title/paragraphs, phone/email, or business hours to be editable from admin, we can:

- Add Customizer fields, or
- Add ACF fields for the Contact page template
