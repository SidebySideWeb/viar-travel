# Walkthrough — WPForms (Contact form)

## Edit the Contact form used on the site

The Contact page embeds WPForms with ID **15**.

1. Go to `WPForms → All Forms`.
2. Find the form with ID **15**.
3. Click **Edit**.
4. Update:
   - Fields and field labels
   - Required fields
   - Notifications (who receives emails)
   - Confirmation (message shown after submit)
5. Click **Save**.

## Test

1. Open the Contact page on the live site.
2. Submit a test entry.
3. Confirm:
   - The success message appears
   - The email notification is received
